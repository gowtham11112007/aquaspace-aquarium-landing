# Aquaspace — Fish Aquarium & Aquascape Service

A modern, responsive, and animated single-page landing website for an aquarium and pet shop, built with clean HTML5, CSS3, and JavaScript.

## Features
- **Modern Responsive Design**: Fully responsive across mobile, tablet, and desktop screens.
- **Scroll-Driven Animations**: Smooth reveal effects, animated counter stats, and dynamic skill progress bars.
- **Floating Ocean Bubbles**: Lightweight dynamic canvas background animation.
- **Interactive Navigation**: Sticky header with elevation changes and back-to-top button.
- **One-Click Inquiries**: Direct phone call and WhatsApp chat integration.

## Deployment
Deployed on Vercel.
